# front_end_development_libraries_projects

Collection of small React projects demonstrating usage of common front-end libraries and patterns.
Contents
- `Calculator/` — A React calculator app using `mathjs`, `redux` and `primereact` components.
- `DrumMachine/` — A keyboard-driven drum machine using React and `react-hotkeys-hook`.
- `MarkdownPreviewer/` — Live Markdown editor and previewer built with React.
- `PomodoroClock/` — Pomodoro timer built with React and `react-icons`.
- `RandomQuoteMachine/` — Random quote generator using `react-bootstrap` and Font Awesome.

Quick Start

Each project is a standalone Create React App. To run any project:

1. Open a terminal and change directory into the project folder, for example:

```powershell
cd "c:\Users\sulta\Desktop\My Projects\front_end_development_libraries_projects\Calculator\calculator"
```

2. Install dependencies (run once per project):

```powershell
npm install
```

3. Start the development server:

```powershell
npm start
```

Build

To create a production build for any project:

```powershell
npm run build
```

Test

Run the test suite (where present):

```powershell
npm test
```

Notes
- These projects were bootstrapped with Create React App and use `react-scripts` (v5).
- Node.js and npm are required. Recommended Node LTS (18 or newer) and npm 9+.
- Each project has its own `package.json` and is independent — install and run them separately.
